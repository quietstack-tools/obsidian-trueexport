# TrueExport

Export Obsidian notes to Word, PDF and HTML that open correctly everywhere —
with your wikilinks, embeds, callouts, tables and footnotes intact.

🚧 **In development. Not yet released.**

## Privacy

TrueExport makes exactly one network request in the entire codebase: licence key
validation, and only when you press **Activate**. No telemetry, no analytics, no
crash reporting, no update checking. **Your note content never leaves your
device.**

Optional remote image fetching is off by default and clearly labelled in
settings.
